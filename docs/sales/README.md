# Sales presentation: AI-Native Autonomous Digital Marketing Department, Social Media MVP v1.0

`AI-Native-Autonomous-Digital-Marketing-Department_Social-Media-MVP-v1.0.html` is the whole presentation in ONE file: no
internet, no folders, no install. Double-click it (any modern browser), press **Present** for full screen, arrow keys or the
space bar to move. Fonts are embedded. Copy it to a USB stick or email it as it is.

Every figure on it was measured on real runs on 2026-10-13 (the replay slide reproduces the run `20261013T111013Z`: 27 ideas,
103 posts, 659,047 tokens, 13:28); the calculators' defaults are labelled examples.

To change it: edit `deck-source.html`, then `python3 build_deck.py` (needs `fonts.css`) rebuilds the single file.
